# 晚点学习来源说明

`youtube-to-weixin-article` 的学习来源包含一组晚点原内容对照样本。样本本地目录为：

```text
N:\C\提纲图文版\outputs\weixin_new2\videos
```

每个样本文件夹中的 `article.md` 和 `原文长图.png` 按晚点原内容处理，分别用于观察文字结构和长图呈现。对应的视频链接、字幕、截图和视频文件用于建立“同源视频资料如何改写成公众号深度长文”的对照关系。

## 原长图入口

晚点原长图不在 README 首页直接展示，单独入口见 [`wandian-original-long-images.md`](wandian-original-long-images.md)。

## 公开仓库处理方式

本仓库说明学习来源和对照方法，但不公开分发晚点原文全文、原始长图、字幕或视频素材。可复用的部分沉淀为：

- `youtube-to-weixin-article/SKILL.md` 中的执行规则；
- `references/weixin-article-rules.md` 中的标题、结构、截图、长图和来源规则；
- `EXPERIMENT.md` 中的实验流程和对照方法；
- `EVALUATION.md` 与 `evals/` 中的评分方法和结果摘要。

如果后续需要在公开仓库展示原图级证据，应先确认版权授权，或改用脱敏截图、局部裁切、低清缩略图、哈希校验和文件清单等方式。
