# 2026-09-23 Opus 5 写作文章双盲对比实验

## 实验目的

在不向独立评估窗口透露材料身份的前提下，对两份关于 Opus 5 与写作者的内容进行质量对比，观察文章的标题、开头、结构、论证、细节、视觉证据和来源呈现是否存在稳定差异。

本记录属于实验过程记录，不是用户版 Skill 的功能说明，也不把未完成的评分写成正式结论。

## 双盲方式

独立窗口被明确要求：

1. 不参考主对话、历史结论、既有评分或用户背景；
2. 不根据文件名、链接形式或任务背景推断材料身份；
3. 不使用“原版”“生成稿”“测试稿”“Skill 产物”等身份标签；
4. 先分别阅读两份材料并独立评分；
5. 再进行盲态维度对比；
6. 最后给出各自优势、各自不足和优先级修改建议。

评分维度包括：

- 标题有效性；
- 开头吸引力；
- 核心判断清晰度；
- 结构组织；
- 小标题质量；
- 论证深度；
- 事实与细节支撑；
- 具体案例和故事信息量；
- 中文语言自然度；
- 面向中文读者的可读性；
- 图片或视觉证据与段落的贴合度；
- 结尾完成度；
- 来源信息完整性。

## 执行过程

1. 独立窗口成功读取材料 A 网页。
2. 独立窗口成功读取材料 B 的文章稿和长图。
3. 独立窗口开始区分“信息覆盖更广”和“证据更扎实”等评分维度。
4. 独立窗口在生成最终评分和修改建议时发生网络流断开。
5. 对同一窗口发送了两次“基于已读取材料直接输出最终评估”的请求，但接口均未返回完整答复。

### 双盲窗口确认的优势

材料 A 更好的地方：

1. 证据更集中，价格、生成片段和重复问题更具体；
2. 结论更克制，清楚区分头脑风暴和正文生成；
3. 篇幅更短，观点推进更快。

材料 B 更好的地方：

1. 中文本地化完成度更高；
2. 将模型能力拆分为文风、提示词、结构分析、成本和头脑风暴等工作环节；
3. 截图和图文编排更适合直接传播。

### 写回用户版 Skill 的内容

本次双盲结果支持写入用户版 Skill 的 3 条规则：

1. 建立事实核验清单：价格、测试条件、样本量、模型版本和结论逐项对照来源；无法核验的内容改成推测或删除；
2. 保持证据密度：每个核心判断至少配一个原句、输出片段、数字、测试条件或贴近段落的截图；
3. 控制扩写和重复：同一结论只保留一次，优先保留“适合什么任务、不适合什么任务、取舍何时值得”的决策信息。

以上 3 条已写入 `youtube-to-weixin-article/SKILL.md`。关于固定开头字数和手机宽度视觉质检，双盲窗口标记为一般建议；本 Skill 已有开头结构和长图视觉检查规则，因此本次不重复新增。
