# evals 说明

这个目录保存 `youtube-to-weixin-article` 的独立评估记录。

评估记录用于说明 Skill 是否真的在独立环境中产生了可见效果。它不是宣传页，也不是模型自夸区。

## 记录什么

每次评估至少记录：

- 评分日期；
- 评分方式；
- 评分窗口或评分者看到的输入；
- 评分窗口或评分者看到的输出；
- 分数或排序；
- 主要优点；
- 主要问题；
- 哪些建议已经写回 Skill，哪些仍待确认。

## 不记录什么

- 不上传原始视频、字幕、公众号长图或受限样本；
- 不复制完整聊天记录；
- 不把主对话分析当作独立评分；
- 不把没有确认的建议写成已经完成的能力。
